서버 연결 (Google Apps Script)

이 항목이 왜 필요한가요? (보안 · 구조 설명)
이 화면(Index.html)은 GitHub Pages에서 열리는 "남의 서버" 페이지입니다. 남의 서버 페이지는 google.script.run 을 쓸 수 없어서, GAS /exec 주소를 직접 알고 있어야 호출할 수 있습니다. 그래서 주소를 이 브라우저(localStorage)에만 저장합니다.

· API KEY는 GAS 쪽 API_KEY 속성과 짝을 이루는 "비밀번호"입니다. 넣으면 주소를 아는 사람도 키 없이는 실행 못 합니다. (선택)
· 저장된 값은 서버로 전송되지 않고, 오직 본인 기기에서만 쓰입니다.
· 주소를 코드에 박아두면 재배포 때마다 GitHub를 고쳐야 하므로, 입력값 저장 방식이 더 안전하고 편합니다.
